This C2 lesson adapts the released Frozen Reference Contract for second-year mechanical-engineering learners who know matrices and basic NumPy but not iterative eigensolvers. It progresses from eigenpairs and the characteristic equation through the symmetric eigenbasis, dominant-component derivation, normalized power iteration, convergence assumptions, sign ambiguity, failure cases, diagnostics, and an executable implementation. The mechanical-vibration framing is explicitly bounded as pedagogical context.

The lesson uses five chapters and reserves the final chapter for exactly three worked exercises: a concept check, a unified power-iteration hand calculation, and a code diagnostic. The hand calculation reports one structured product, normalized vector, Rayleigh quotient, residual, and residual norm, with a normalization consistency check. The code exercise includes executable validation of the positive-integer iteration requirement and a visible expected stdout value.

Automatic checks are configured for Frozen Contract binding, required and conditional item coverage, section and exercise provenance, prose length, exercise structure, the topic-matched numeric chain, visible answer equality, and executed stdout equality. These checks establish treatment protocol integrity only; they do not establish complete mathematical correctness or answer the RQ1 comparison.
