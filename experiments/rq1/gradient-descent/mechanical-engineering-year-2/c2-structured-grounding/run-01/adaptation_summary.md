# Adaptation summary

## Learner-profile normalisation

The target learner profile is a second-year mechanical engineering student who has studied calculus, vectors and basic Python, but has not studied formal convex optimisation. The lesson therefore emphasises physical intuition, simple examples and direct links between mathematics and code.

## Adaptation decisions

The teaching narrative has been re-planned around potential energy, equilibrium and numerical relaxation. This creates a mechanical engineering entry point before introducing the standard optimisation notation. The lesson preserves the source definitions of unconstrained optimisation, stationary points, smoothness, convexity, gradient descent, momentum, stochastic methods and second-order methods, while reducing the most proof-heavy material.

## Source-coverage decisions

The main source ideas are retained and reorganised into a single coherent lesson. The detailed convergence proofs in the source are reduced to concise explanatory statements, while the core algorithmic rules and mathematical definitions are preserved. A single executable Python example is included to make the theory-to-implementation link explicit.

## Provenance and tracing

The provenance file records the source sections used for each core idea and notes where the adaptation changes the presentation. The main transformations are preservation, reordering and summarisation. The most technical proof material is deferred rather than omitted without explanation.

## Source issues reported

The source contains some extraction artefacts and minor formatting irregularities in formula presentation. These issues were preserved as source-level concerns rather than silently repaired, and the adaptation keeps the intended mathematical meaning intact.

## Final review findings

The adapted lesson is mathematically faithful to the source at the level of definitions, equations and algorithmic structure. It is aligned to the stated learner profile, uses British English, stays within the requested length range and includes a worked Python example plus five exercises. The result is a single long-form teaching resource rather than a page-based atomic lesson.
