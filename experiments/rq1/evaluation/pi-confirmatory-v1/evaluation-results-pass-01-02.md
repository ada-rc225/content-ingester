# PI 背景 RQ1 自动评估结果（Pass 01-02）

## 结论摘要

基于当前 Power Iteration confirmatory-v1 的 9 个匿名 lesson 和 18 个独立 evaluator pass，`c2-structured-grounding` 在 fidelity 指标上呈现最强的描述性结果：重大/严重错误率为 **0.00%**，语义漂移率最低（**5.56%**），条件失败率最低（**0.00%**），公式准确率为 **100.00%**，算法准确率最高（**87.50%**）。`c1-source-conditioned` 同样没有重大/严重错误，并取得最低的不受支持陈述率（**1.91%**）。`c0-ungrounded` 的主要错误率、语义漂移率、不受支持陈述率最高，公式与算法准确率最低。

这仍是小样本、单主题、AI judge 的操作性评估，不是统计显著性或专家 ground truth。与旧 dev 结果不同，这次 C2 的三个 run 在 blind bundle 中是 3 个唯一 prepared 文本，因此当前报告可以按 3 个名义 run 汇总，但仍不做因果显著性检验。

## 主要问题模式

- C0 的弱点主要体现在语义漂移、不受支持陈述和公式/算法准确率；其中 S003 出现一次 generation-required 重大/严重错误，S004 漂移率最高。
- C1 保留公式最稳定，三份 lesson 的公式准确率都是 100%，不受支持陈述率最低；剩余问题主要是实现契约和部分条件细节。
- C2 在三份 lesson 中保持 0% 重大/严重错误、0% 条件失败率和最高算法准确率；剩余分歧多是实现边界项，例如正 tolerance / `max_iterations` 验证、异常类型、返回值顺序等。

## evaluator 可靠性

共评估 9 个匿名 lesson，每个 lesson 两个 fresh pointwise evaluator context，共 18 个 pass。两个 pass 使用同一模型但互相不能读取结果。

| 重复性指标 | 总体结果 |
|---|---:|
| 严重度精确一致率 | 95.68% |
| coverage 精确一致率 | 96.30% |
| drift-set 精确一致率 | 94.44% |
| 教学评分平均绝对差 | 0.063 / 5 |

这些一致率衡量同一 AI judge 的重复性，不表示与专家判断或真实正确性的符合程度。汇总没有人工选择某一次 pass，而是固定地先在 lesson 内平均两个 pass。

## 解释边界

这些结果是 AI agent 基于 Frozen Contract 的自动化操作性测量，不是人工专家 ground truth。每组只有三个 run，且只覆盖一个 Power Iteration 主题；两个 pass 来自同一模型，只能评估重复性，不能替代跨模型或专家效度。本报告不报告 p 值、因果效应或单一综合分数。
