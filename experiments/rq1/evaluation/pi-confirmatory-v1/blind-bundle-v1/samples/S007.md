# Eigenvalues, Eigenvectors, and the Power Iteration


## Eigenpairs and the characteristic equation

### A direction a matrix preserves

Suppose a real square matrix $A$ acts on a non-zero vector $v$. Usually, matrix multiplication changes both the length and direction of $v$. An eigenvector is a special exception: the result has the same direction, possibly reversed, and only its scale changes. The defining equation is

$$Av=\lambda v.$$

Here $v$ is the eigenvector and the scalar $\lambda$ is its associated eigenvalue. The requirement $v\ne0$ matters. The zero vector satisfies $A0=\lambda0$ for every scalar, so it cannot identify a meaningful direction or eigenvalue.

In mechanical modal reasoning, an eigenvector can be read as a pattern of relative components that a matrix action preserves. That framing is useful for visualising a mode, but it is only a teaching interpretation of the matrix equation; it does not add a physical claim to the algebra. The entries of $v$ can be positive or negative, and multiplying the whole vector by a non-zero scalar describes the same eigendirection.

### Finding eigenvalues exactly

Rearranging the eigenpair equation gives $(A-\lambda I)v=0$. A non-zero solution exists only when the matrix $A-\lambda I$ is singular. Therefore eigenvalues satisfy the characteristic equation

$$\det(A-\lambda I)=0,$$

where $I$ is the identity matrix of compatible size. For a small matrix, expanding this determinant can be an effective exact calculation. For a large matrix, explicitly forming and solving the characteristic polynomial is often not the preferred numerical strategy. An iterative method can instead use repeated matrix-vector products, which is the computational route developed here. These are two ways to seek spectral information, not an assertion that an iterative product is algebraically identical to forming the polynomial.


## Symmetry, modal directions, and dominance

### The real symmetric setting

The cleanest power-iteration explanation applies when $A$ is real and symmetric, so $A=A^T$. The spectral theorem then gives an orthonormal basis of real eigenvectors. If the eigenvectors are the columns of $Q$, then

$$A=Q\Lambda Q^T,\qquad \Lambda=\operatorname{diag}(\lambda_1,\ldots,\lambda_n).$$

Any vector $x$ can be resolved into these orthogonal directions:

$$x=\sum_{i=1}^n c_i v_i,\qquad c_i=v_i^Tx.$$

The coefficient $c_i$ measures the projection of $x$ onto the corresponding eigenvector. This expansion is valuable because applying $A$ does not mix these directions: it multiplies each component by its eigenvalue.

### Dominant means largest magnitude

Order the eigenvalues by absolute value:

$$|\lambda_1|>|\lambda_2|\ge\cdots\ge|\lambda_n|.$$

The strict first inequality makes $\lambda_1$ unique in magnitude. It is the dominant eigenvalue for power iteration. “Largest” here means largest magnitude, not largest algebraic value. For example, between $5$ and $-8$, the value $-8$ is dominant because $|-8|> |5|$. The associated eigendirection is the target, even though the eigenvalue is negative.

This distinction prevents a common interpretation error in engineering computation: a method that amplifies the component with largest absolute scale is not automatically selecting the most positive eigenvalue.


## Deriving one power-iteration step

### Multiplication followed by normalization

Start with a non-zero vector $x_0$. A power-iteration step first computes

$$y_{k+1}=Ax_k,$$

and then normalizes it:

$$x_{k+1}=\frac{y_{k+1}}{\|y_{k+1}\|_2}.$$

Normalization controls scale without changing direction. It also prevents repeated multiplication from making the vector extremely large or extremely small. The denominator must be non-zero; if $Ax_k=0$, the method has broken down and division must not be attempted.

To see why the dominant direction emerges, write the initial vector in the symmetric eigenbasis. Repeated multiplication gives

$$A^kx_0=\sum_{i=1}^n c_i\lambda_i^kv_i
=\lambda_1^k\left(c_1v_1+\sum_{i=2}^n c_i\left(\frac{\lambda_i}{\lambda_1}\right)^kv_i\right).$$

The leading factor changes scale. Inside the brackets, each subordinate component is multiplied by a ratio whose magnitude is less than one. If $c_1=v_1^Tx_0\ne0$ and there is a strict magnitude gap, these ratios tend to zero as $k$ grows. The direction therefore approaches $v_1$, up to sign.

### A transparent implementation

The implementation should make data checks and algorithm order visible. Convert inputs to floating NumPy arrays, require a square matrix and a compatible one-dimensional starting vector, and reject a zero starting vector. Normalize $x$ before entering the loop. For each iteration, form $y=Ax$, check its norm before division, normalize, calculate the Rayleigh estimate and residual, and return as soon as the residual norm is no larger than the positive tolerance. If that does not happen, the maximum iteration count is the fallback.

A valid `max_iterations` value is a positive integer. Invalid values should raise a clear `ValueError` before the loop starts. The return structure is $(\text{eigenvalue},x,\text{residual norm},\text{iteration count})$.


## Convergence, estimates, and diagnostics

### Assumptions and asymptotic rate

For a real symmetric matrix, power iteration generally reduces direction error asymptotically at a rate governed by

$$\left|\frac{\lambda_2}{\lambda_1}\right|^k.$$

This statement requires a unique dominant magnitude, a non-zero initial projection onto $v_1$, and no zero iterate $Ax_k$. It is an asymptotic description, not an unconditional finite-iteration error bound. A small spectral gap makes the ratio close to one, so convergence can be very slow even though the dominant magnitude remains unique.

If $v_1^Tx_0=0$, exact multiplication cannot create the missing dominant component. The method then cannot converge to $v_1$ in exact arithmetic. This is different from slow convergence: the relevant direction is absent from the starting vector. If $|\lambda_1|=|\lambda_2|$, dominance is repeated and a unique eigenvector need not be selected. These cases explain why checking assumptions is part of using the algorithm rather than an optional theoretical detail.

### Sign, quotient, and residual

When the dominant eigenvalue is negative, normalized iterates may alternate between approximately $v_1$ and $-v_1$. This is not failure in direction: those vectors describe the same eigendirection. Comparing vectors by subtraction can therefore be misleading.

For a non-zero vector, estimate the eigenvalue with the Rayleigh quotient

$$\rho(x_k)=\frac{x_k^TAx_k}{x_k^Tx_k}.$$

If $x_k$ is normalized, this reduces to $\rho(x_k)=x_k^TAx_k$. For symmetric $A$, as $x_k$ approaches $v_1$, the quotient estimates $\lambda_1$. The corresponding residual is

$$r_k=Ax_k-\rho(x_k)x_k.$$

An exact eigenpair has zero residual. The norm $\|r_k\|_2$ is a useful stopping measure because it tests the eigen-equation directly and is not confused by a sign flip.

### Scope beyond symmetry

Power iteration can apply to some non-symmetric matrices, but the orthogonal real eigenbasis used in the derivation is not generally available. Defective matrices, complex dominant eigenvalues, and non-normal behaviour require additional care and are outside this lesson's convergence explanation. Thus the code may accept a general square matrix, while the clean guarantee must be stated only for the real symmetric setting.

### A worked matrix result

For $A=\begin{bmatrix}4&1\\1&2\end{bmatrix}$ and $x_0=(1,1)^T$, the characteristic equation gives exact eigenvalues $3+\sqrt2$ and $3-\sqrt2$. The first is dominant. The first multiplication is $y_1=(5,3)^T$, and normalization produces a vector close to the dominant eigendirection. Iterating the implementation estimates $3+\sqrt2$ and produces a small residual. The sign of the returned vector is not prescribed; either orientation represents the same direction.

### Reading the algorithm as a numerical procedure

The order of operations is important when translating the mathematics into software. The starting vector is first converted to floating-point storage so that division produces a numerical vector rather than an unintended integer result. Its shape is checked separately from its norm: a vector with the wrong number of entries cannot be multiplied by the matrix in the intended eigenproblem, while a correctly shaped zero vector contains no direction at all. These are different input errors and should receive different explanations.

At each pass, the matrix-vector product is the central operation. The product contains the direction information for the next iterate, while its norm supplies only the scale that normalization removes. A breakdown check belongs between these two operations. If the product norm is zero, the program should raise an error instead of constructing a vector by dividing by zero. This ordering also makes the implementation agree with the mathematical condition that the normalizing denominator be non-zero.

The tolerance and iteration limit serve different purposes. A positive residual tolerance asks whether the current vector already satisfies the eigen-equation closely enough for the computation. The positive integer limit guarantees that an unsuccessful run still terminates after a known number of passes. Returning the estimate, vector, residual norm, and count gives a caller enough information to judge both the numerical result and the effort used to obtain it. A small residual is evidence that the returned pair nearly satisfies the equation; it does not by itself identify whether the eigenvalue is the largest algebraic one, nor does it remove the symmetric-matrix assumptions behind the convergence explanation.

For a matrix arising in a modal calculation, it is therefore sensible to inspect more than one output. The eigenvalue estimate indicates the scale associated with the current direction. The vector records relative modal components, but its global sign is conventional. The residual norm measures equation satisfaction. The iteration count shows whether the stopping tolerance was reached quickly or whether the maximum limit was used. Looking at these values together helps separate a valid sign flip from a breakdown, a small spectral gap, or a starting vector that missed the target direction.

State the convergence assumptions that apply, identify the target, and explain what changes if the dominant eigenvalue is negative, if the projection is exactly zero, or if the two largest magnitudes are equal.


#### Worked solution

With a strict ordering $|\lambda_1|>|\lambda_2|\ge|\lambda_3|$, the magnitude-$9$ eigenvalue is uniquely dominant. The non-zero projection supplies a dominant component, and the iteration also requires that no multiplication produces a zero vector. Under the real symmetric setting, direction error generally decreases asymptotically according to $|\lambda_2/\lambda_1|^k=(3/9)^k$.

A negative dominant eigenvalue can make successive normalized vectors alternate sign, but the eigendirection is unchanged. An exactly zero initial projection means exact power iteration cannot create that component, so it will not converge to the dominant eigenvector. Equal largest magnitudes remove unique dominance, so a unique eigenvector need not be selected. The target is the largest magnitude eigenpair, not necessarily the most positive eigenpair.

### Exercise 3 — Code diagnostic

A proposed eigensolver normalizes the initial vector but does not check whether `max_iterations` is a positive integer, and it divides by the product norm before checking for breakdown. Identify both semantic problems. Then use the corrected implementation below to compute the worked matrix result. Why is the residual test preferable to checking only whether consecutive vectors are close?


#### Worked solution

The iteration limit must be validated before the loop, because zero, a negative value, or a non-integer makes the requested iteration semantics ambiguous. The product norm must be checked before division, because a zero product is a breakdown rather than a valid normalized vector. The corrected function preserves square-matrix, dimension, and non-zero-start checks, normalizes before iteration, checks breakdown before division, uses a positive tolerance, and returns four values.

```python
import numpy as np
import json

def power_iteration(A, x0, epsilon=1e-10, max_iterations=1000):
    A = np.asarray(A, dtype=float)
    x = np.asarray(x0, dtype=float)
    if A.ndim != 2 or A.shape[0] != A.shape[1]:
        raise ValueError("A must be square")
    if x.ndim != 1 or x.shape[0] != A.shape[1]:
        raise ValueError("x0 must be one-dimensional and compatible")
    if np.linalg.norm(x) == 0:
        raise ValueError("x0 must be non-zero")
    if epsilon <= 0:
        raise ValueError("epsilon must be positive")
    if isinstance(max_iterations, bool) or not isinstance(max_iterations, (int, np.integer)) or max_iterations <= 0:
        raise ValueError("max_iterations must be a positive integer")
    x = x / np.linalg.norm(x)
    for iteration in range(1, max_iterations + 1):
        y = A @ x
        norm_y = np.linalg.norm(y)
        if norm_y == 0:
            raise ValueError("breakdown: A @ x is zero")
        x = y / norm_y
        eigenvalue = float(x @ A @ x)
        residual_norm = float(np.linalg.norm(A @ x - eigenvalue * x))
        if residual_norm <= epsilon:
            return eigenvalue, x, residual_norm, iteration
    return eigenvalue, x, residual_norm, max_iterations

value, vector, residual, iterations = power_iteration([[4, 1], [1, 2]], [1, 1])
print(json.dumps({"eigenvalue": round(value, 6), "residual_below_1e-10": residual <= 1e-10, "iterations": iterations}))
```

The final residual test checks the eigen-equation directly. Vector differences can look large merely because a negative dominant eigenvalue flips the sign, so successive-vector similarity alone is not a reliable stopping criterion.
