# RQ1 Gradient Descent confirmatory-v1 评估结果

## 评估范围

- 协议：`RQ1-EVAL-v1`
- 评测器：`rq1-judge-sol`（OpenAI Codex CLI，`gpt-5.6-sol`）
- 匿名样本：9 份；每个实验条件 3 份独立课程输出
- 评测轮次：每份样本 1 个 blind judge pass
- 状态：9/9 份 `score_report.json` 均通过 schema、哈希、证据摘录与确定性计分校验

本报告将 fidelity 与 pedagogy 分开报告，不计算单一总分。错误率、漂移率、遗漏率与不支持主张率越低越好；公式和算法准确率越高越好。

C1 的不支持/矛盾主张率最低。C2 的该指标略高，主要来自两份课程中新生成代码练习的预期输出与实际修正代码互相矛盾，而不是 Frozen Contract 核心知识错误。

## 结论

这轮结果支持 RQ1 的预期机制：相较于无 grounding，提供 source context 已消除生成必需项中的重大/关键错误；进一步使用结构化 Frozen Contract，则大幅减少条件丢失和语义漂移，并把公式与算法准确率提升到接近 100%。

不过，这仍是 operational pilot，而不是可直接宣称统计显著或评测器可靠性的最终 confirmatory 结论。当前每个条件只有 3 份课程、每份只有 1 个 AI judge pass，尚未估计同一评测器的重复稳定性或多评测器一致性。正式论文报告应补充至少一次独立重复评测，并报告 agreement/reliability；若不补充，应把本结果明确标注为单评测器、单轮自动化测量。
